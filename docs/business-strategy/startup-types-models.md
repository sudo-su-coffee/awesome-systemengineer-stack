# Startup Types & Business Models — Comprehensive Reference

## 1. By Growth Funding
| Type | Description |
|---|---|
| Bootstrapped | Self-funded, no outside capital |
| Angel-funded | Early individual investor capital, pre-institutional |
| Venture-backed | VC capital, growth-at-all-costs trajectory |
| Seed/Series-staged | Structured rounds (Pre-seed → Seed → A → B → C → IPO) |
| Crowdfunded | Kickstarter/Indiegogo, reward or equity-based (Wefunder, Republic) |
| Revenue-based financing | Capital repaid as % of revenue, no equity dilution (Pipe, Clearco) |
| Grant-funded | Govt/foundation grants (common in deep tech, biotech, defense) |
| Corporate spin-off | Incubated inside a parent firm, then spun out |
| Debt-financed | Venture debt layered on top of equity rounds |

## 2. By Scale Ambition
| Type | Description |
|---|---|
| Lifestyle Startup | Optimized for founder freedom/income, not scale |
| Small Business Startup | SME with modern tooling, regional market |
| Scalable Startup | Built for venture-scale TAM from day one |
| Buyable Startup | Engineered for acquisition (feature/team acquihire or product tuck-in) |
| Social Startup | Impact-first, profit-secondary |
| Zebra Startup | Profitable + ethical, rejects winner-take-all unicorn logic |
| Unicorn / Decacorn / Hectocorn | $1B / $10B / $100B private valuation tiers |
| Camel Startup | Built for resilience across funding winters (vs. blitzscaling) |

## 3. By Revenue Model
| Type | Description |
|---|---|
| B2B | Selling to companies (SaaS, enterprise infra) |
| B2C | Selling to consumers directly |
| B2B2C | Platform sits between business and end-user (Shopify, Uber Eats) |
| B2G | Selling to government (defense, civic tech, GovTech) |
| C2C / P2P | Peer marketplaces (OLX, Airbnb) |
| D2C | Brand sells direct, no intermediary retail |
| Freemium | Free tier + paid upgrade |
| Subscription / SaaS | Recurring revenue, usually MRR/ARR tracked |
| Usage-based / Metered | Pay-per-call, pay-per-compute (AWS, Twilio, Stripe) |
| Marketplace | Commission on transaction (Amazon, Etsy) |
| Aggregator | Single brand, fragmented backend suppliers (OYO, Zomato) |
| On-demand / Gig | Real-time service matching (Uber, Swiggy) |
| Franchise | Local operators license a proven model |
| Open-core / Open-source | Free core, paid enterprise layer (Red Hat, GitLab, Elastic) |
| API-first / Platform-as-a-Service | Infra sold as composable API primitives (Twilio, Stripe, Plaid) |
| Licensing / IP-based | Revenue from patents, tech licensing (ARM model) |
| Hybrid | Multiple stacked revenue streams |

## 4. By Legal Structure (India-specific + Global)
| Type | Description |
|---|---|
| Sole Proprietorship | One owner, unlimited personal liability |
| Partnership / LLP | Shared ownership, LLP caps liability |
| Private Limited Company | Standard Indian startup vehicle (Companies Act, 2013) |
| One Person Company (OPC) | Single-founder limited liability entity (India) |
| Public Limited Company | IPO-eligible structure |
| Section 8 Company / Trust / Society | Indian non-profit legal forms |
| Cooperative | Member-owned, common in agri/dairy startups |
| LLC (US) | Pass-through taxation, liability shield |
| C-Corp / Delaware C-Corp | Standard VC-fundable US/global structure |
| GIFT City / IFSC entity | India's offshore-equivalent structure for fintech/fund startups |

## 5. By Innovation Style
| Type | Description |
|---|---|
| Tech Startup | Software/hardware-led |
| Deep Tech | AI, robotics, biotech, advanced materials — long R&D cycles |
| Hard Tech / Frontier Tech | Space, semiconductors, energy, defense — capital + regulatory intensive |
| Service Startup | Skills-based delivery (consulting, agencies, dev shops) |
| Product Startup | Tangible/physical SKU |
| Platform Startup | Multi-sided network effects (Facebook, Uber, UPI itself) |
| Infrastructure Startup | Picks-and-shovels for other startups (Stripe, Cloudflare, Twilio) |
| Ecosystem Enabler | Accelerators, dev tooling, SaaS-for-SaaS |
| Sovereign / GovTech Infra | Nation-scale rails — UPI, Aadhaar, INDUS-class hardware, e-Governance stacks |

## 6. By Methodology
| Type | Description |
|---|---|
| Lean Startup | MVP → Build-Measure-Learn loop (Eric Ries) |
| Customer Development | Get-out-of-the-building discovery before building (Steve Blank) |
| Design Thinking | Empathize → Define → Ideate → Prototype → Test |
| Agile / Scrum-driven | Sprint-based iterative delivery |
| Disciplined Entrepreneurship | 24-step structured framework (Bill Aulet) |
| Exponential Organization (ExO) | 10x scaling via leveraged assets, not owned ones (Salim Ismail) |
| Jobs-to-be-Done | Build around the "job" the customer is hiring the product for |
| Blitzscaling | Prioritize speed over efficiency under uncertainty (Reid Hoffman) |

## 7. By Industry Vertical
| Type | Examples |
|---|---|
| Fintech | UPI rails, neobanks, payment gateways, embedded finance |
| Healthtech | Telemedicine, diagnostics, digital health records |
| Agritech | Farm-to-market, precision agriculture, GIS-based advisory |
| Edtech | Online learning, skilling platforms |
| Cleantech / Climate tech | Renewable energy, carbon accounting |
| Spacetech | Launch, satellites, ground systems, ISL (inter-satellite links) |
| Defense tech | Drones, surveillance, dual-use hardware |
| Govtech / Civic tech | Citizen services, e-Governance, public infra digitization |
| Logistics tech | Fleet, warehousing, last-mile |
| Proptech | Real estate discovery, management, construction tech |

## 8. By Technology/Architecture Approach
| Type | Description |
|---|---|
| API-first | Product is consumed as a programmable interface before any UI |
| No-code / Low-code | Visual builders abstracting away custom code |
| Open Source-first | Community-built core, monetized via hosting/support |
| Hardware-software hybrid | Embedded firmware + cloud control plane (IoT, robotics) |
| Sovereign-stack | Self-hosted, vendor-lock-free infra (relevant to DPDP-compliant builds) |
| AI-native | Model/inference is the product core, not a bolt-on feature |

## 9. By Exit Strategy
| Type | Description |
|---|---|
| IPO-bound | Built for public listing |
| Acquisition-bound | Built to be acquired by a strategic or PE buyer |
| Roll-up | Acquires smaller players to consolidate a fragmented market |
| No-exit / Perpetual | Founder intends to run indefinitely, often profit-funded |
